## 7. Tech units and the Tech Vault

13. Tech is a new resource: "Stolen Tech". It uses the normal resource systems: storage, crew carrying, transfer between ships, and trade.
14. Only the Tech Vault part stores tech.
15. The Tech Vault is a buildable part. Its rules define its size, health, cost and capacity. Defaults: 1×1, 3,000 health (3 × a vanilla storage tile, below 1×1 armor at 4,000), 8 steel (requirement 447), capacity 2 units (1 tile × stack size 2). Rules changes need a game restart. There are no vault tiers (requirement 440).
16. To move tech between ships, the players build a vault on the other ship. The crew then carry the tech over, like any other resource. On one ship, the vanilla move resources tool moves tech between vaults.
17. A new run starts with `StartingTechUnits` (default 8) in the Tech Vaults of the starting ship. The starter ship has the vaults by design (requirement 1010); the run only fills them (requirement 1014). In co-op each player commands only their own ships, so the first ship of each player gets an equal share of the units (8 = 4 + 4 for two players, 2 vaults each).
65. A Tech Vault loses its tech only when it is destroyed. Damage that leaves the vault standing costs no tech. A destroyed vault drops the units inside it as tech crates in space, or with chance `VaultTechLossChance` destroys them (requirement 445). The loss comes out of the vault storage, so the fleet count and the vault art always agree (requirement 449). Salvage is not destruction by an enemy: when crew salvage a vault (a derelict, or a vault taken apart for a move), it drops all its tech as crates when it goes (resource drop rate `StorageSalvaged` = 100 %). Removed: the step rule (one unit lost at each `VaultDamagePerUnitLost` × max health of damage). Its last hit was often a tiny one, which read as a bug.
66. Removed: the repair rule. Partial damage costs no tech (requirement 65), so a repair has nothing to give back.
