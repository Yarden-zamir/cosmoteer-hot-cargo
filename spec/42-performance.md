## 42. Performance

Co-op runs in lockstep, so the game runs at the speed of the slowest machine. Hot Cargo code that runs every frame runs on every machine, also on a slow client. So frame code does little work, and sim code caches what it asks often. Measure: autotest command `selfprof` (`Telemetry/SelfProfile.cs`), test `telemetry-stress` (single player) and co-op session `coop-stress`. Host settings for a slow client: `TUNABLES.md`, "A slow co-op client".

870. **Trait cache.** `PersonalityStrategy.Traits` keeps its result for one sim tick on the ship's `HcPersonality` module. A new build measure, another player index or other tunables compute it again. The cache is not sim state: a fresh computation gives the same value.
871. **Stable text.** A vanilla UI update that sets a label's text in every frame, with a Hot Cargo postfix that appends to it, writes to a scratch label. The real label gets the final text once, so it lays out again only when the final text changes. This covers the comms list row (`CallShipItem.Update`: station and faction badges) and the hire tab crew line (`CommHireTab`: the heat line). Code: `Ux/StableText.cs`.
872. **Frame code.** HUD texts that change all the time refresh every `Ux.HudRefreshSeconds` (default 0.25 s) of real time, not in every frame: the heat panel texts, the status overlay, the wanted timer, the heat zone line and the event dialog, which builds its page from sim state (`UxKit.HudDue`). Event buttons still send their input at once. The dialog's co-op hover report holds for 2 × `HudRefreshSeconds`, so the hover message (requirement 602) does not switch off between refreshes. The stage alert strip and the galaxy map hide still act in the same frame. Code that runs for every ship blip, crate marker or HUD hook in every frame uses loops, not LINQ, has no closures, and allocates nothing when it shows nothing.
873. **Tagged ships.** `SimQueries.TaggedShips` filters the stasis spawners by tag first and then sorts the matches by ID, with the same result as before. Hunter, event, mission and chain code calls it in sim ticks.
