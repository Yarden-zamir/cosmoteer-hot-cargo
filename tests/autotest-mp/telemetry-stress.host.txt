# Heavy co-op fight for a performance measure (spec 870 to 873), host side. Run it with 3 players: autotest-all.sh mp3:telemetry-stress.

# among rocks, events and diplomacy hails on. selfprof times every Hot Cargo entry point on the host.
mphost {PORT}

mp godmode on
mp maxhunters 16
mp strikeinterval 20
mp airocks 10 900
mp aispawn pirates 4

expect selfprof_pct_tick < 25
