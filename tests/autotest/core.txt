# Core heat loop: new career, heat, stages, fame heat, time heat, save and load.
newgame run
wait 8
log start
expect active == 1
expect sector == 1
heat 30
expect stages == 1
# One standard tier-1 fame unit is 5 fame x 1.5 (default difficulty) x 1.0 (RewardScale) = 7.5 fame. 30 fame = 4 units.
# That is 4 x 1.5 heat (HeatPerStandardMission) x 1.2 (multiplier with 8 tech) = 7.2 heat.
fame 30
expect heat >= 37.1
expect heat <= 38.0
expect stages == 1
wait 20
expect seconds > 5
save core
wait 3
load core
log loaded
expect heat >= 37.1
expect stages == 1
heat 100
expect stages == 4
quit
