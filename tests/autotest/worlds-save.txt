# Worlds objectives in a save (spec 226): a pass hold in progress and a sundive with a carrier keep their state after a load.
newgame run
wait 8
godmode
worlds jumpto hc_mining_belt
pause off
worlds set PassHoldSeconds 600
worlds generate sundive
worlds accept sundive
worlds goto sundive
wait 10
expect worlds_sundive_carrier == 1
worlds generate pass
worlds accept pass
worlds goto pass
wait 3
worlds kill hc_pass_raider
wait 4
expect worlds_pass_held > 2
save worlds
load worlds
wait 3
pause off
worlds reselect pass
expect worlds_pass_held > 2
expect worlds_pass_done == 0
worlds reselect sundive
expect worlds_sundive_carrier == 1
expect worlds_sundive_done == 0
expect sector == 2
quit
